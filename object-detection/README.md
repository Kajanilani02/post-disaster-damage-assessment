# Object Detection for Post-Disaster Damage Assessment

This module focuses on detecting disaster-related objects from ground-level images collected in Sri Lanka.

## Models Evaluated
- YOLO11n
- YOLOv8s
- RT-DETR-l

## Detection Classes
- Landslide
- Uprooted Tree
- Structures
- Debris

## Dataset
The annotated dataset contains 1,349 images, divided into training and validation sets.

## Implementation
The Jupyter notebooks contain the model training, evaluation, and comparison workflows.

## Best Lightweight Baseline
YOLO11n achieved 91.3% precision and 88.4% mAP@50 in the reported experiments.

*Note: Results apply to the current dataset and experimental setup.*
